# 长期记录与 Metadata

继承适用 `AGENTS.md` 的通用记录规则；本参考只规定项目状态摘要和关键入口索引的职责。

## 建立与读取

- 项目没有同类 metadata 时，只有用户明确要求，或已确认后续使用方、失效条件且没有合适承载位置时才新增。
- metadata 缺少新鲜度证据、与当前事实冲突或超出标注范围时，只把它用于导航，不让它定义目标或当前状态。

## 内容边界

- `project-metadata.md` 只保存项目目的、当前重点、已验证且仍有效的结论、活动阻塞、正式入口或活动计划指针，以及最近验证依据。
- `file-metadata.md` 只索引正式入口、核心配置、承担目标真源职责的关键文档和测试入口。
- 两类 metadata 都标明适用范围和最近验证依据，不保存任务流水、完整 changelog、运行日志、生成物或全量文件清单。

## 更新与失效

- 只有 metadata 是当前授权影响范围内的正式资产，且本次结果会使现有条目失实时，才重写对应当前条目并删除被替代内容。
- 不在文件尾追加另一份“当前状态”，也不把自动记录的对话、goal 或文件操作复制为 metadata。
- metadata 过大、重复、过时或混入历史流水时，不继续完整读取或追加；授权包含记录维护时重写为当前摘要，否则明确其不新鲜状态并改用定向来源。
