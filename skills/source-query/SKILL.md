# Source Query

## 路由

按当前仍缺的证据选择最低充分层级：

1. 已知文件、名称和少量结果：直接有界读取或受限原生 fd/rg，不加载 backend 协议。
2. 全集、不存在证明、大结果压缩、分页或特殊原生模式：读取 [rg-fd.md](references/rg-fd.md)，调用 PATH 中的 `srcq.exe`。
3. 文本不能可靠表达语法结构、完整范围、控制流、rule 或 rewrite：读取 [ast.md](references/ast.md)。
4. 结论依赖真实定义身份、重载、类型、精确引用、层级或 Provider 诊断：读取 [lsp.md](references/lsp.md)，只发现当前缺失的最小 LSP 能力。

项目大小、Provider、冷暖状态和已有定位会改变相邻层级的成本；它们只影响优先级，不形成永久禁用。证据充分后立即停止，不为了解工具先调用 help、doctor、capabilities 或无关查询。

## 运行与证据边界

- `srcq.exe` 是独立安装到用户 PATH 的唯一运行时。正常查询直接调用；命令确实不可用或报告版本错误时，返回安装、升级或开启新终端的恢复动作，不搜索项目构建目录、Skill、插件或 Codex 缓存中的私有副本。
- 先限定可靠的源码根、目录、文件类型、glob、pattern 或符号；全集和不存在结论必须绑定权威范围、原生状态和完整性，局部页不得外推。
- 只把支撑当前判断的位置、范围、正文、关系和限制带入上下文；需要续页时沿用同一 snapshot 和精确 cursor。
- AST 不替代必要正文阅读，LSP 不重复文本或 AST 已证明的事实。修改类能力仍受上位授权约束，包装器和工具选择不创建写入或进程许可。
