# 执行与完成合同

本文件唯一维护任务投影、结果记录和最终完成集合；通用 ID 与条目格式继承 [artifact-contracts.md](artifact-contracts.md)。任务文件的字段、状态与存储细则由 `$task-table-manager` 维护。

## 任务与结果

- 任务只承载可执行且有真实产出的方案动作，引用 `SOL/GAP/DES/AC/REQ`，并声明依赖、消费内容、产出、修改范围和验证方式；同一声明可能随载体、模式、状态、版本、revision 或持久化边界变化时，额外声明会改变行为或 oracle 的验证维度。
- 公共产出与消费者接入拆分时，任务图保留实际消费关系；只有创建模块或接口而没有当前消费者或用户结果，不构成完成任务。
- 任务图除表达真实依赖外，还应保存 `$execution-governor` 已裁决的证明动作、首个真实消费者与横向范围的消费关系；共享前提或首个消费者尚无有效证据时，依赖它们的任务不是可交换的平级候选。该关系必须来自真实消费，不新增深度评分，也不让 CLI 裁决前沿或优先级。
- 结果只记录实际产出、有效验证、改变的文件、未解决问题、被推翻的上游 ID、直接覆盖的验证维度值或已证等价类，以及工作实际依据的上游版本。完成时刻的当前版本不能替代实际输入版本，单一 fixture 或组合通过不能扩大到未覆盖维度。
- 状态、表格行数、结果文件存在或局部检查通过都不证明上游语义或用户结果正确。

执行一个方案动作或任务时所需的语义闭包、扩展条件和证据回流由 [iteration.md](iteration.md) 定义；`taskctl context` 可以压缩返回这组输入，但不判断其语义是否充分。

## 最终完成合同

当前范围的最终目标集合只来自当前执行周期共同澄清并由用户确认的 Markdown 中全部 `REQ/AC/UDES`；至少存在其中一项，不应只有约束。缺少目标是语义诊断，不是快照写入的机械门禁。

最终复核逐项取得直接适用的执行结果和验证证据，确认整体结果在语义、范围、优先级和用户可观察结果上未偏离目标，确认适用 `CON` 仍满足，并复核全部当前 `DCR` 而不由 CLI 预先筛选。任何 DCR 仍表明受保护目标无法满足时，当前范围不能完成。

若所选方案改变长期 owner、正式契约、权威状态或共享行为，完成证据还覆盖修改前后实际影响范围内的消费者和派生产物：每项已经证明仍有效，或已完成更新、迁移、退出、重做或重新验证，且没有仍依赖旧语义或来源版本未知的适用结果。这是所选实现成立的必要证据，不把 `DES/SOL` 升格为用户目标，也不授权清理无关历史问题。

`DES/OBS/GAP/SOL/DEC`、任务合同、任务状态、生成视图、引用覆盖和工具诊断都是中间产物。模型设计、分析、方案、任务状态、快照、索引、结构检查和各阶段审核都只是中间结果；任务 `done` 只表示该任务记录的结果已提交，不能替代当前用户确认目标的最终复核。
