# Subagent Orchestration

先确认当前接口与角色可用；安装文件或历史角色列表不证明可派发。模型与档位由角色配置维护。

## 选择与交接

- **evidence**：优先承担当前尚缺的源码、文档、配置、日志或工具用法定位；既可建立陌生模块的入口地图，也可补齐调用关系、复用点和验证位置。范围可从问题与目录起步，不要求先知道具体文件或证明搜索很复杂。按 [evidence-packet.md](references/evidence-packet.md) 交接；消费者读关键原文分析，已有证据充分即停止，不例行重复复核。
- **experiment / advanced-experiment**：只承接能将整段探索交出、最终集中审核的较大实现。短小或需主代理持续裁决的工作直接做；十来分钟只是成本线索，不是硬门槛。困难/视觉实验仍须满足独立交付条件。读 [experiment-lifecycle.md](references/experiment-lifecycle.md)。
- **operator**：对象、步骤和判定明确的必要操作，预计有长输出、多轮等待或结果检查时优先委派，包括构建、测试、打包及批量处理。命令简单不排除隔离价值；已有入口能直接给简短结果、无需多轮观察时自行执行。读 [operator-execution.md](references/operator-execution.md)。

先复用有效结果；上下文相关、归属清楚时用 `followup_task` 续派，否则 `spawn_agent`。固定角色显式 `fork_turns="none"`，任务给目标、范围、必要来源和预期交付；写入再给文件所有权、用户改动及恢复边界。任务说明不要求固定表格。派发失败时按实际错误处理，不空等。

两类 experiment 可在当前实验内按需委派一层 evidence，无需额外授权；evidence 与 operator 不得创建子代理或创建/分叉用户任务。仅跨分支移交派发权、结果送达不明或归属冲突时读 [coordination.md](references/coordination.md#证据复用与派发交接)；普通创建、同派发者续用和接纳不加载它。

## 等待与接纳

派发后只做独立且必要的工作，不同时代做同一子问题；没有独立工作时调用 `collaboration.wait_agent(timeout_ms=1800000)`，即默认显式等待 30 分钟，宿主限时和必要沟通要求优先。一次等待可接收多个子代理的消息，任一结果或用户输入可提前唤醒。无新事件的超时不构成新证据，继续等待，不轮询、催报或重想同一状态。

两类 experiment 独立推进、最终集中交付；中断条件由实验引用维护。主代理不例行审阅试错或追发建议，只有新用户要求、共享前提反证或实际资源冲突时及时介入。operator 集中交付，按角色指令处理中断；不要求普通阶段汇报。

按实际差异、验收合同与关键来源接纳，具体反例或证据缺口才深入，不重放全部探索或重写已合格实现。多个结果先处理推翻共同前提者，暂停其依赖工作；只重验最终修改影响的部分。Git、发布和整体完成由主代理负责。
