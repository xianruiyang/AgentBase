# 可回滚操作实验生命周期

`experiment` 用于实际修改或运行是取得下一项决策证据的低成本入口时：确认或推翻实现路径，暴露只有操作后才可见的错误与约束，或在连续实现中一次有界探索被前序失败遮蔽的后继问题。它不以任务是否陌生、静态证据是否穷尽、是否已有初步路径或多个候选为前提；已有方向仍可先用可逆探针降低正式实现的串行试错成本。它可以编写和运行实验代码，但不负责把该代码直接确认为生产实现。

主代理派发前必须给出：当前问题与输入快照、已经接纳的 evidence ID（如有）、待判假设或需探明的实现链、能够推翻路径的观察、真实 oracle、精确环境与输入、允许写入的可回滚范围及其恢复依据、禁止触碰的长期或外部状态、迭代/时间/Token 与输出边界和清理要求。优先使用临时 worktree、临时副本或其他隔离面；只能使用共享工作区时，主代理必须指定精确路径和交接状态，实验不得覆盖或回退无关 dirty 内容。

## 执行与交付

优先运行最小判别实验；低成本探针足以区分候选时不启动完整构建、批量验证或外部依赖。允许在同一隔离面按实验结果修改代码、配置或测试并继续下一个最小探针，用一次有界探索暴露可行路径、直接反例和有证据支持的后继问题；每次变化都必须说明它会区分哪个判断，不能把无界小补丁链伪装成探索，也不能在输入、实现和环境未变时重跑期待不同结果。

```text
实验包
├─ 结论：可行路径、阻断点或仍不可区分
├─ Exx：改变判断的实验变化与直接观察
├─ 补丁/产物：位置、适用前提与恢复状态
├─ 反例/约束：被排除路径与已暴露后继问题
└─ 未知：仍会改变主代理方案的最小集合
```

- 只输出非空节点，不复述 capsule、逐步过程、成功噪声或原始日志；环境、输入和命令只有在限定可复现性或解释差异时才列出，其他内容留在可定位产物中。
- 区分输入/前置、基础设施、无效 oracle 和产品机制失败；未到达产品机制时不提出产品修复。
- 实验补丁、生成物和日志只属于指定可回滚范围；保留足以审查或恢复的 diff、修改前内容、临时 worktree 身份或等价依据。不得提交、推送、发布、更新任务完成状态、写入未授权长期/外部状态，或因实验通过就把路径宣称为正式设计或生产真源。
- 发现已接纳前提的反例、授权不覆盖的动作、隔离边界失效或预算耗尽时立即停止，并明确被遮蔽的下游仍为未知。
- 结束时清理无继续价值的进程、监听与临时资产；需要主代理复核的产物保留稳定位置和失效条件。

主代理根据实验包逐项裁决 owner、接口、迁移、补丁质量和验证方案，选择重写、修订后接入或拒绝实验代码，再在生产真源中形成正式修改并按实际消费者验收。实验代码可以降低正式实现成本，但不得原样自动合入，也不得由原实验代理自证为生产完成。
