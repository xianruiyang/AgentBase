# AgentBase 根需求收益边缘持续优化：目标设计

## DES-001 根需求到运行时行为的权威分层

- 状态: confirmed
- 来源: 项目真源与发布合同
- 满足: REQ-001, AC-001, AC-002

`docs/requirements.md` 唯一定义项目长期需求；`global/AGENTS.md` 只承接跨项目常驻认知内核；skill 按触发条件承接详细流程和领域协议；工具只承担机械辅助；正式部署入口负责从项目真源生成安装副本。不得复制整份需求到运行时规则。

## DES-002 单轮收益闭环

- 状态: confirmed
- 来源: REQ-001, UDES-001
- 满足: AC-001, AC-002, AC-003, CON-001
- 依赖: DES-001

每轮从根需求与当前证据形成候选，按质量收益、适用频率、Token/复杂度成本和可验证性选出一个最高净收益差距；在其正确 owner 修正并闭合实际消费者，验证、独立评估、发布和读回后才进入下一轮。停止条件由剩余候选的净收益决定，不以预设轮数替代。
