## 约束与保留边界

- CON-001：本轮没有以减少预读为由删减目标保护、影响闭合或最终完成集合。
- CON-002：正式规则没有固定 Token、调用次数、文档数或命令配方，也没有加入运行时正反例。

- CON-004：未向实际 Codex 根目录发布；需要用户针对下一次 `Publish` 另行明确同意。

## 完成判断与重开条件

在项目候选范围内，本轮全部 `REQ/AC/UDES` 已有直接产物和适用验证，全部 `CON` 满足，没有 DCR。根需求当前已由正式 owner 覆盖，但它们是持续能力而非永久完成状态；出现阶段引用误选、必要上下文缺失、固定预读复发、最终复核漏项、公开 owner 或消费者变化，或真实任务显示质量/端到端成本退化时，重开本后继计划或其明确替代计划。
