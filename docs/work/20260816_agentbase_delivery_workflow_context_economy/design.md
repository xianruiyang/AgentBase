# AgentBase 交付工作流渐进上下文下一版：目标设计

## DES-001 交付产物合同按稳定职责分层

- 状态: confirmed
- 满足: REQ-001, AC-001, CON-002
- 关联: UDES-001

`delivery-workflow` 的主入口只维护工作流内核和引用选择；通用条目结构、受保护目标、可修订规划以及执行与完成分别由一个正式引用文件唯一维护。阶段细则不在主入口和多个引用中重复定义。

## DES-002 当前动作决定最低充分引用集合

- 状态: confirmed
- 满足: AC-001, AC-003
- 依赖: DES-001

建立或修改阶段产物时读取通用合同与对应阶段合同；判断推进或新证据回退时增加迭代合同；使用 CLI 时增加工具合同；执行/恢复和最终复核分别读取其直接适用合同。选择依据是当前动作，不是文件总数或固定预算。

## DES-003 执行入口维护最小语义闭包规则

- 状态: confirmed
- 满足: AC-002, AC-003, CON-003
- 依赖: DES-001

`delivery-workflow` 负责定义跨阶段执行所需的最小语义闭包和扩展条件；`task-table-manager` 只把已形成的任务合同、上游条目与依赖结果压缩返回，不另行定义交付目标。模型根据证据判断是否需要扩展，CLI 不计算充分性。

## DES-004 最终完成合同保持独立完整

- 状态: confirmed
- 满足: AC-004, CON-003
- 依赖: DES-001

最终完成合同由执行/完成引用与迭代复核规则共同承载，始终能够追溯到受保护目标、约束、DCR、直接证据和适用影响闭包；阶段渐进加载不得修改完成集合。

## DES-005 项目验证覆盖入口、边界与消费者

- 状态: confirmed
- 满足: REQ-002, AC-005, AC-006
- 关联: UDES-001, UDES-002

静态合同验证所有正式引用存在、只在一个位置定义关键阶段语义，并检查主入口的阶段路由与最小闭包边界。`development/skill-routing` 的 References 阶段按声明的条件引用型 skill 统一构造候选、可选引用和结果，不再硬编码某个 skill；skill 结构校验和独立 detached 评估覆盖触发与行为没有退化。项目总计划索引本后继计划并保留专项计数在专项证据中。
