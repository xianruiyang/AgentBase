# 用户目标设计

## UDES-001 使用短句柄 `@next` 命令

- 状态: confirmed
- 来源: 用户 2026-08-22 在真实使用中指出完整 cursor/argv 复制不便；2026-08-23 进一步确认临时句柄最多六位并循环复用已失效编号
- 关联: REQ-001, REQ-002, AC-001, AC-002, AC-003, AC-004, AC-005

保留现有不透明 cursor 和 snapshot 作为 srcq 内部与 machine 合同，但 query model 页尾不再重复它们：`@more` 只说明仍有多少证据，`@next` 只携带 `srcq more q<number>`。新句柄从 `q1` 开始、不补零，只使用 `q1` 至 `q999999`，到达上限后循环选择已经不在现存 registry 中的编号。句柄是有界临时游标，不是永久身份；不得为淘汰记录保存永久历史。是否成立由真实 CLI 的第一页—续页命令链、身份、回卷边界和后端调用次数裁决，而不是由格式审查或模型最终自述裁决。
