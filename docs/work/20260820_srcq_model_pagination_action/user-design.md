# 用户目标设计

## UDES-001 使用短句柄 `@next` 命令

- 状态: confirmed
- 来源: 用户 2026-08-22 在真实使用中指出完整 cursor/argv 复制不便，确认采用短句柄方案并要求实现、安装和发布
- 关联: REQ-001, AC-001, AC-002, AC-003

保留现有不透明 cursor 和 snapshot 作为 srcq 内部与 machine 合同，但 query model 页尾不再重复它们：`@more` 只说明仍有多少证据，`@next` 只携带 `srcq more q<number>`。句柄按实际使用量从 `q1` 单调增长，不固定成六字符随机码；是否成立由真实 CLI 的第一页—续页命令链、身份和后端调用次数裁决，而不是由格式审查或模型最终自述裁决。
