基线是提交 `86ee057306659da6e615a7d33580184f8c543cb8`。候选先按 owner、读取时点、删除后果和当前消费者逐项裁决，再用同一 `tiktoken 0.13.0 / o200k_base` 计量；字节、行数或平台已有相似指令都不构成删除证据。
