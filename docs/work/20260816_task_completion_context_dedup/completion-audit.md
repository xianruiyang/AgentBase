## 真实输入证据

对上一后继交付工作区使用相同目标范围、参数和 snapshot 复测：

- 改动前为两页 106,313 UTF-8 字节，包含 28 次完整候选对象，但只有 3 个唯一任务；候选对象序列化中的 85,347 字节属于重复。
- 改动后为一页 20,642 字节，减少 85,671 字节、约 80.6%；仍有 10 个目标、4 个约束、0 个 DCR、28 条目标—任务关系和 3 个唯一任务。
- 28 个引用均能在同页目录解析，目录没有无人引用任务；旧目标内嵌字段为 0，12 项候选证据字段全部存在，snapshot 未改变且诊断数为 0。

该证据直接证明本轮结构重复已消除且事实集合闭合。响应从两页收敛为一页也减少了一次续页需求，但没有运行独立模型 Token 或时间实验，因此不把它表述为端到端收益。

最终 detached Routing、Policy、References 运行分别覆盖 73、73、19 个场景，并合并为 `development/skill-routing/evidence/current.json`。Routing 满足全部声明约束，但保留 3 个非严格场景的额外选择警告；首次 Routing 运行有 6 项过选或漏选，已被验证器拒绝且未进入正式证据。全新隔离运行提高逐案判断投入后通过，没有修改候选规则、放宽 oracle 或向评估器披露失败用例。
