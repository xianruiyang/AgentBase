# 任务完成复核证据去重下一版：目标设计

## DES-001 taskctl 拥有完成复核输出投影

- 状态: confirmed
- 满足: REQ-001, AC-001, AC-003, CON-003
- 关联: UDES-002

`task-table-manager` 的文档继续定义候选证据输出合同，`taskctl completion-context` 作为唯一辅助入口从同一任务、状态、结果和 Markdown 快照生成投影。交付文档仍定义目标与完成语义，不新增状态源、完成裁判或跨 skill 复制实现。

## DES-002 页级目录规范化多目标共享任务

- 状态: confirmed
- 满足: AC-001, AC-002, AC-003
- 依赖: DES-001

响应顶层 `candidate_tasks` 是按任务 ID 键控的页级对象；对象值保存与目标无关的完整候选任务证据且不重复 `id`。每个 `targets[]` 只通过有序 `candidate_task_ids` 表达当前候选页，原有逐目标计数、截断和游标字段继续描述该关系。

## DES-003 预算裁剪维护引用闭包

- 状态: confirmed
- 满足: AC-004
- 依赖: DES-002

候选目录只包含当前返回目标实际引用的任务。目标因预算被移除时同步重建目录；字符串有界缩减继续作用于唯一对象，最小响应和现有分页门禁不改变。任何返回的候选 ID 都必须在同页目录存在，目录不得携带当前页无人引用的任务。

## DES-004 当前消费者直接迁移到唯一新结构

- 满足: AC-005, AC-006
- 依赖: DES-002, DES-003

仓库当前只存在 `taskctl` 实现与单元测试消费者。测试直接改为读取页级目录和目标 ID，不保留旧嵌套字段；工具合同明确新结构。独立评估验证 skill 路由与策略未因合同修改退化，真实工作区验证表示机制与证据等价边界。
