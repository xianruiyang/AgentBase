# 任务完成复核证据去重下一版：需求分析

## REQ-001 完整完成复核使用最低充分输出

- 状态: confirmed
- 来源: 用户确认应修改已发现的 `completion-context` 重复输出，并要求继续推进项目根需求下一版本
- 关联: AC-001, AC-002, AC-003, AC-004, CON-001, CON-002

最终复核仍取得每个当前目标的全部适用候选证据，但同一次响应中语义相同的完整任务证据只传输一次；目标只保留准确关联，使模型不因表示层重复承担额外上下文。

## AC-001 页内每项完整任务证据只返回一次

- 状态: confirmed
- 来源: REQ-001 对根需求 AC-007、AC-030 的本轮投影
- 关联: REQ-001

`completion-context` 在响应页顶层返回按任务 ID 唯一的候选任务目录；多个目标关联同一任务时不重复嵌入任务结果、验证、来源快照或诊断。

## AC-002 目标到候选证据的关系保持准确

- 状态: confirmed
- 来源: REQ-001 对根需求 AC-014、AC-028、AC-030 的本轮投影
- 关联: REQ-001

每个目标返回该目标当前页的有序候选任务 ID，并保持候选总数、返回数、结果数、带验证结果数、截断状态和精确续页游标；每个返回 ID 都能在同页候选任务目录中唯一解析。

## AC-003 任务证据语义不得因去重缩减

- 状态: confirmed
- 来源: REQ-001 对根需求 AC-014、AC-026、AC-028 的本轮投影
- 关联: REQ-001

页级目录仍完整保留旧输出中每项任务的状态、合同修订、结果引用、结果摘要、产出、验证、未决项、失效来源、证据关联、证据引用、执行来源快照和结果诊断；去重只改变表示，不改变模型可复核的事实集合。

## AC-004 有界预算与分页快照继续成立

- 状态: confirmed
- 来源: REQ-001 对根需求 AC-018、AC-031 的本轮投影
- 关联: REQ-001

目标、候选、约束和 DCR 继续按既有流分页并绑定同一 `snapshot_id`；未知游标、快照变化和续页无法重建当前 Markdown 的门禁语义保持不变。预算裁剪后不得留下无法在同页目录解析的候选任务 ID，也不得为节省输出混用快照。

## REQ-002 下一版本闭合真实消费者与直接证据

- 状态: confirmed
- 来源: 用户要求继续推进 `docs/requirements.md` 并迭代下一版本
- 关联: AC-005, AC-006, CON-003, CON-004

本轮在负责完成复核压缩的正式 owner 中修正已证实差距，退出旧嵌套表示，更新当前仓库消费者、文档合同、测试、独立 skill 证据、总计划和完成审计，不为未发现的外部消费者保留平行输出。

## AC-005 旧嵌套表示从当前正式入口退出

- 状态: confirmed
- 来源: REQ-002 对根需求 AC-006、AC-021、AC-025 的本轮投影
- 关联: REQ-002

当前目标行不再返回重复的完整 `candidate_tasks`；仓库中的测试与文档全部消费页级目录和 `candidate_task_ids`。没有已证实的仓库外消费者时不保留兼容字段、模式开关或第二输出入口。

## AC-006 用原场景证明机制和完成范围

- 状态: confirmed
- 来源: REQ-002 对根需求 AC-027、AC-028、AC-033 的本轮投影
- 关联: REQ-002

以本轮 10 个目标、3 个唯一任务的真实复核工作区和受影响回归验证：目标关联与证据内容不丢失、分页与门禁不退化、页内重复显著消失；刷新当前候选的独立 skill 证据并逐项完成审计。结构字节只证明该输入表示，不外推为模型端到端 Token 或速度结论。

## CON-001 质量优先于输出压缩

- 状态: confirmed
- 来源: 根需求 CON-001
- 关联: REQ-001, REQ-002

不得删除最终复核目标、证据字段、约束、DCR、诊断、来源版本或分页保护来换取更短输出；只有语义与证据同等充分的表示才可采用。

## CON-002 不建立固定压缩比例门槛

- 状态: confirmed
- 来源: 根需求 AC-007、CON-003
- 关联: REQ-001

正式规则只要求消除无语义增益的重复并保持可解析闭包，不规定固定字节、Token、比例、调用次数或页大小；测量值只保留为本轮直接证据。

## CON-003 CLI 继续只提供复核输入

- 状态: confirmed
- 来源: 根需求 REQ-005
- 关联: REQ-002

`taskctl` 只压缩返回当前文档、任务和结果，不判断证据充分、目标通过、DCR 是否阻断或整体完成。

## CON-004 发布仍需当次明确授权

- 状态: confirmed
- 来源: 根需求 AC-035 与项目发布合同
- 关联: REQ-002

本轮可修改项目真源、验证、提交并按既有授权同步 Git；再次发布到实际 Codex 根目录必须另行取得用户针对该次发布的明确同意。
