# AgentBase 交付链十二轮审查与改进：用户设计

## UDES-001 使用当前更新后的交付流程

- 状态: confirmed
- 来源: 用户请求
- 关联: REQ-001, AC-003

沿用当前 `delivery-workflow` 与 `task-table-manager` 的受保护基线、可修订阶段、任务结果和最终复核机制，不建立脱离该流程的平行审查记录。

## UDES-002 审查至少迭代十轮

- 状态: confirmed
- 来源: 用户请求
- 关联: REQ-001, AC-001

审查按至少十轮不同的证据面连续推进；后轮要消费前轮结果，必要时推翻、修订或补强前轮结论。

## UDES-003 当前请求内一次性完成且不使用 Goal

- 状态: confirmed
- 来源: 用户请求
- 关联: REQ-001, CON-001

本轮在当前对话连续完成分析、实现、验证、最终复核和项目同步，不创建 Goal 作为续跑或推理深度状态。
