## 评分与证据范围

[审计 JSON](audit-current-rule-iteration-v1.json) 保存逐次费用、耗时、请求、候选失败编号和原答案证据。同义表达接受，compound required 按完整行为判断；原范围不能补足最终答案中缺失的行为；已有文件身份可分组引用。当前未改对照的原始答案完整保留在外部结果，不能用尚未完整评分的对照推导质量优势。

五组原始根均为 `D:\AgentBaseBench\<审计中的 name>\pilot-ready`，含 experiment、summary、逐次 JSONL 和 audit-capsule；全部 postflight 无报错、capsule 核验通过，每组核验 12 个原始文件。UE 的校验通过只证明声明范围：实际轨迹还读取了 `plan/NEW_THREAD_HANDOFF.md` 与 `plan/workflow.json`，它们未在该片的身份范围，故保留输入范围限制；后续最终对照需纳入相关计划依赖。这不改变已经核对的源码答案事实，也不把未证变化说成已发生的漂移。
