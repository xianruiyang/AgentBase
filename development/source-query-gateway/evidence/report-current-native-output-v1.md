# C# 原生输出详略迭代：可比候选，尚非稳定全对

## 结果与边界

用户将本阶段限定为 C# 快速迭代，禁止针对语言、项目或题目特化。保留当前全部治理职责、当前自有 skills 和原样历史批量条款，只试原生输出详略设置及一条通用目标保留候选。题面、oracle、工具与推理深度未改。

最接近旧版的是 `model_verbosity = "high"`。同轮确认严格评分 **58/62 对 58/62**，候选实际均价下降 **17.06%**；但两侧各有一项语义解释敏感点，因此只能认定本组达到严格最低线、形成可比候选，不能认定稳定恢复、全面优于旧版或全题目标完成。保持候选不变，不围绕 C# 继续追加提示词；未修改生产规则、skill、config、工具或安装态，未部署或发行。

本报告由后续候选选择与跨轮恢复消费，评分依据在[结构化审计](audit-current-native-output-v1.json)，完整事件和冻结身份在下表外部目录。报告是模型读取摘要；审计保存逐项裁决、最终答案与费用；机器身份/逐请求事件仍由正式 runner 的 manifest、summary、capsule 唯一持有。原始证据缺失或语料、规则、模型、环境改变时，本结论不得直接复用；摘要可从审计与原始结果重建。

确认轮四份答案的六个定义范围和七个调用位置均正确。candidate1为7行，其余依次为control1 12行、control2 11行、candidate2 12行，均未超行数。

## 机制与防过拟合

本机 Luna 元数据声明支持 verbosity，默认 low；隔离配置原未设置该键。medium/high只控制输出详略，不改变受测 `reasoning_effort=medium`。配置字段及取值见[官方配置参考](https://learn.chatgpt.com/docs/config-file/config-reference)。这证明设置的职责，不证明它必然改善正确率。

候选仍为完整当前治理规则、自有13个skills、历史原样两条批量规则和原答复规则。没有加入任何语言、项目、符号名称、答案、31项检查表或12行特化。目标保留候选只在隔离规则中强调保留明确交付事实/条件/范围/精度，但成绩更差，因此拒绝该方向，不把实验条款写入生产。

确认候选实际工具批次分别为 `2,3` 与 `1,2,3`，两份各2次真正多工具请求，最大批次3；不是 shell 串联。旧版也有实际批量。四份均无非零命令退出。当前证据更支持“查询位置已经正常，但最终答复偶尔丢语义”，而非需要 C# 特殊搜索路径；小样本不能把价格/质量变化全部归因于 high。
