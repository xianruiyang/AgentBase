## 位置错误与旧评分差异

只核对答案明确提供的路径和位置，不从工具输出补答案。同一文件已建立完整身份后允许分组与唯一回指；不因为没有复述状态发布、行为、完整性或静态边界而扣正式分。同一个错误位置只扣对应目标一次，不另扣全局准确性项。

单行定位核对目标行本身；给出以标准行开头的短范围时，该起始行已明确提供，但不能把未给出的内部行补进答案。例：注册 `58–61` 给出了注册起始行 `58`，并未给出内部委派的 `60`；`cleanup 179–181` 是闭包范围，不是移除监听语句的 `180`。要求完整实现范围的目标则核对两端。此口径对新旧双方一致应用，因此 TS 不能直接沿用旧审计中偏宽松的位置通过结论。
