## 不用隐藏答案证明题面已明确

正式runner在 `development/code-search-benchmark/experiment.py:1649` 只向模型发送 `READ_ONLY_PREFIX + case["prompt"]`，不发送 required/oracle。先前独立核对曾混用 required 的精确描述并错位编号，主代理未接纳该结论，要求仅据 prompt 重核后确认：

- 原题写“说明宿主侧与 React Webview 侧分别如何注册、分派”，没有明确要求宿主监听回调向私有方法的委托调用。隐藏R3指定60行，但私有方法220行switch也可以被理解为“分派”。
- 原题写“是否和如何清理消息处理器”及“其他位置…行号”，没有唯一指明移除监听调用语句。隐藏R7指定180行，而回答cleanup范围179–181与题面仍有合理对应。
- 定义范围、源码行号和隐藏评分对象本身没有发现错误。问题在于模型可见任务没有完整明确评分所选对象，不在于允许包围范围代替已明确要求的调用点。不能因旧版偶尔猜对就证明题面唯一，也不能据此把全部历史失分自动改为正确。

此前题面审查不充分；旧v24结果继续作为原合同下的记录和机制参考，但这部分差额不再单独证明规则造成退化。三份已查trace仍证明正确证据进入了上下文；它不证明模型可见任务唯一要求输出隐藏oracle所选位置。
