触发用例去掉普通文本/文件题中的工具答案提示，补文件列表和已知行范围直接读取两个相近边界。skills、批量规则、工具实现、输出详略、题面和 oracle 都没改；没有增加 Hook、拦截器、别名转发或门禁。真实 o200k_base 计数：全局规则 4818 → 4877 Token，增加 59。
