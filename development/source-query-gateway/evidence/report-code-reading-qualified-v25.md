仓库只采纳已测候选的两处通用规则改写：明确且无冲突的请求直接作为任务合同；临时名称/目录/类型过滤不单独证明完整对象范围。不加入位置字段、精确行号、语言、符号或题目答案提示，不采用失败的通用交付提醒。批量和srcq-only入口保持，skills与srcq未改动；没有部署或发行。

## 题面修正、复用与因果边界

TS旧题泛称“分派/清理”，但隐藏评分分别指定监听回调的委托与移除监听语句。只向模型发送prompt的正式入口不发送required/oracle，后者明确不等于题面明确。[合同复核](report-ts-contract-alignment-v25.md)据此创建v25，仅把四个既有调用定位对象写进可见任务，不改标准答案和评分，也不提示查询工具。

双方都重测同一v25 TS题，各两次，均7/7；没有把旧版v24分数与新题拼接。此改善是题面合同澄清后的观察，不能称为规则或srcq提升。失败的delivery-coverage候选没有进入本次环境，旧分数与费用保留。

其他八题的prompt、required、oracle、评分、源码指纹与v24逐项相同，复用同一个范围候选及同一旧版的已验证原始记录。AgentBase使用同源、去除development研究材料与原历史的源码fixture；其他项目使用既有正式源码范围。所有环境仍为各自13个项目owned skills、相同srcq0.7.0与CLI、Luna medium/low/default、HTTP-only、受测模型不创建子代理。源目录不反向决定仓库；采纳的是有研究来源和明确语义的两处规则补丁，并验证正式global正文与受测候选一致。

这是一份明确选择证据的逐题汇总，保留五个manifest身份，不伪装成单一experiment。旧external分片仍含原TS运行，但其四份TS答案不进入本表；其他未改动case保留原结果。五个capsule的100份原始文件校验一致，所选36份答案/usage/价格匹配，无postflight失败。所选正式答题合计$0.32584920；五个入口预检合计$0.04151528，预检不分摊到逐题均价。旧TS、污染样本及失败消融另存，不包含在所选正式答题合计中。
